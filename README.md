# POC Itau GenAI

Estrutura base para a prova de conceito com Streamlit, LangGraph, RAG e AWS.

## Estrutura

- `app.py`: interface Streamlit
- `src/graph.py`: workflow LangGraph oficial
- `src/settings.py`: configuracoes
- `src/llm.py`: integracao com LLM
- `src/rag.py`: pipeline RAG
- `src/tools.py`: ferramentas auxiliares
- `data/politicas/`: taxonomia de documentos para indexacao e consulta
